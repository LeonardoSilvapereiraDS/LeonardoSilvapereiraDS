## Projetos

### FinControl Enterprise

Aplicação de **controle financeiro pessoal e de caixa**, com versão web responsiva e aplicação para Windows. Organiza receitas, despesas, contas, metas e orçamentos em espaços separados.

- **Tecnologias:** C#, ASP.NET Core, Windows Forms, Entity Framework Core e SQLite.
- **Organização:** camadas de domínio, aplicação e infraestrutura.
- **Recursos:** usuários e permissões, importação de extratos, exportação CSV e backup financeiro.
